# Vision Tech - Site Web Professionnel

Site web professionnel pour Vision Tech, électricien spécialisé en électricité générale, vidéosurveillance, énergie solaire et climatisation.

## 🚀 Déploiement

### Netlify
- Poids optimisé : ~102 MB
- Temps de déploiement : 2-3 minutes
- Configuration : `netlify.toml` et `_redirects`

### Fonctionnalités
- Design responsive
- Galeries d'images optimisées
- Formulaire de contact
- Navigation moderne

## 📁 Structure

```
visiontech/
├── data/           # Images des projets
├── index.html       # Page principale
├── index.css        # Styles
├── netlify.toml     # Configuration Netlify
└── _redirects      # Redirections SPA
```

## 🎨 Technologies

- HTML5 sémantique
- TailwindCSS
- Font Awesome
- JavaScript moderne
- Design responsive
